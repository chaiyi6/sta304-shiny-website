# Generative AI in Education: What Students Told Us

An interactive R Shiny website exploring generative AI usage among STA304 students.


## Live Website

https://01a219a2-a9be-f9b2-eeaa-c871257a7c49.share.connect.posit.cloud/ 


## Website Features

- Key findings from the survey
- AI usage by purpose
- Student opinions on generative AI
- Relationship between AI usage and perceived efficiency
- Interactive data filters and plot settings
  

## Tools Used

- R and R Shiny
- GitHub
- Posit Connect Cloud
